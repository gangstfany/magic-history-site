四个目录各自是独立Git仓库，均使用main。不要在父目录提交，也不要再把新的课程修改提交到旧magic-history仓库的course/apwh、feature/ap-art-history-*分支。旧仓库和原部署仍保留用于恢复。

每次修改先进入对应目录，查看 `git remote -v`，确认远端仓库名正确，再提交推送。例：世界史改动只在magic-history-apwh中提交；其发布流程不会checkout或覆盖首页源码。

首页的课程地址在modules.json中配置。两个课程独立部署，浏览器加载各自最新版；首页文件及账号版本不随课程发布变化。账号使用固定SHA的源码依赖，只有明确更新首页auth-release.json才切换版本。

艺术史采用最新已提交的250件作品版本。原艺术史工作区未提交的补图、文字和脚本草稿未覆盖、未删除、未上传；详见艺术史仓库README的迁移说明。

账号界面与本地来源校验已验证；没有创建用户、发邮件或执行真实Google登录。需在现有Supabase项目确认以下回调地址被Redirect URLs白名单覆盖：
